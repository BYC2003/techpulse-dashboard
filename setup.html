安装与来源说明

这是一个参考资讯看板逻辑搭建的手机网站：今日要闻、分类标签、来源等级、时间、摘要、原文链接都放在同一页。没有每日推送，打开即读。

1. 部署到 GitHub Pages

  1. 新建 GitHub 仓库，把整个项目上传到 main 分支。
  2. 进入 Settings → Pages，Source 选择 Deploy from a branch，分支选 main，目录选 /(root)。
  3. 进入 Actions，运行 Update AI News Snapshot 一次。
  4. 等待采集和发布完成。

工作流每小时检查一次来源。GitHub 的定时任务可能排队延迟；如果你要求严格实时，需要改用 Cloudflare Cron 或常驻服务器。

2. 安装到荣耀手机

  1. 从 Google Play 安装或更新 Chrome。
  2. 用 Chrome 打开部署后的 Pages 地址。
  3. 点右上角菜单，选择“安装应用”或“添加到主屏幕”。
  4. 以后从桌面图标直接打开，界面会保持手机版布局。

3. 看板栏目

GitHub：GitHub Blog、Changelog、Trending、仓库与 Release 动态。

开源：Show HN、Hacker News、Product Hunt、HelloGitHub 与实用工具。

科技：Google / Apple / NVIDIA 官方消息，以及 TechCrunch、The Verge、Ars Technica、MIT Technology Review、Wired、Engadget、Solidot、IT之家、爱范儿、InfoQ、少数派、量子位。

AI：OpenAI、Google DeepMind、Google AI、Hugging Face、Microsoft Research、MIT News AI 等。

论文：arXiv 与 Berkeley AI Research。

4. 来源等级

一手官方研究/预印本社区发现媒体核验定制 RSS

“只看一手”按钮会保留官方来源和研究/预印本，隐藏媒体与社区内容。卡片上的等级标签告诉你这条信息是原始发布、社区发现，还是需要进一步核验的媒体报道。

5. 时效与准确性

时效：先抓取官方 RSS/API，下一次定时运行纳入最新条目；不是秒级实时。

准确性：卡片保留来源标题、摘要和原文链接，不使用 AI 自动改写；预印本明确标为未经同行评审。

稳定性：静态网站 + GitHub Pages，没有数据库；单个来源失败不会让整个页面失效，底部可以查看来源健康状态。
